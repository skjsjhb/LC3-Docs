# ICS-S-1 文本即数据

:::info

这是一项**可选实验** —— 不占据平时分比例。正因此，它的编号与其它实验有所不同。不过，该实验能提供额外的总评加分。

:::

在有汇编器之前，人们是怎么编写程序的？当然，你已经知道答案了 —— 甚至已经做过类似的事情。第一个汇编器从何而来？显然，第一个汇编器是手工用机器码排列而成的，而且它的功能非常有限，也少不了错误和漏洞。当有了一个汇编器后，人们就用它来编写下一个汇编器，这个版本会比上一个版本更加方便和稳定，然后再是下一个，再下一个……一直到高级语言编译器，再到各种现代应用程序。

我们不去重新体验“用机器码来排列汇编器指令”的功能，毕竟那可不是什么愉快的回忆 —— 但我们仍然能从汇编器运行的过程中窥知一些早期程序设计的小巧思。

## 目标

编写一个 LC-3 汇编器。

- 从标准输入读入 LC-3 代码，并以文本形式（字符 `'1'` 和 `'0'`）将机器代码输出到标准输出。
- 输入的 LC-3 代码不会存在错误，并且已经经过规范化（参见后续描述）。
- 源代码仅包含一个程序段（即一对 `.ORIG` 和 `.END`）。
- 输出的机器代码须在第一行标注装载地址，随后每条指令一行。
- 源代码可能包含任意 LC-3 汇编指令。
- 可以使用任何支持标准输入和输出的语言（也包括 LC-3！）来编写程序。

## 输入输出样例

输入：

```
.ORIG x3000
AND R0, R0, x0
HALT
.END
```

输出：

```
0011000000000000
0101000000100000
1111000000100101
```

## 输入程序规范

所有的 LC-3 源代码都符合如下限制条件，以方便汇编器的编写：

- 行与行之间以 LF `\n` 分隔，可能有空行。
- 源代码可能有注释，注释以分号 `;` 开始，至所在行的末尾结束。
- 每个非空行仅包含一条指令（包含伪指令，下同），每条指令也仅会写在一行中。
- 指令可能会有不定数目空格的缩进。
- 如果指令有标签，标签会放在同一行，位于操作码前，且与操作码之间有一空格。
- 操作码与操作数之间有一空格。
- 每两个操作数之间以逗号加空格 `, ` &nbsp;分隔。
- 标签、操作码和寄存器名为大写，立即数前缀 `x` 及其字母为小写。
- `.STRINGZ` 后的字符串以双引号 `"` 包裹。
- `.STRINGZ` 的字符串若包含转义符，则只有 `\n` 一种。
- `.BLKW` 后的操作数没有立即数前缀。
- 带有汇编名称的中断（如 `HALT`）会使用其中断名，而不是 `TRAP` 与立即数的组合。
- 源代码仅包含可打印 ASCII 字符。
