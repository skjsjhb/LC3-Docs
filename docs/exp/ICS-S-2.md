# ICS-S-2 数据即代码

:::info

这是一项**可选实验** —— 不占据平时分比例。正因此，它的编号与其它实验有所不同。不过，该实验能提供额外的总评加分。

:::

世界上并没有一台真正的商业 LC-3 计算机（当然，不算上那些载有 LC-3 实现的 FPGA 电路），也不会有人为这样的指令集编写操作系统。如果想要运行 LC-3 程序，我们就需要一个**运行环境（Runtime）**。不过，与使用 Verilog 来构造电路解释指令不同，在这个实验中，我们主要关注指令功能的实现。

## 目标

编写一个 LC-3 运行环境。

- 输入包含文本形式（字符 `'1'` 和 `'0'`）的机器代码，以及一组提问，以空行分隔。
- 一行只包含一条机器代码或一项提问，先解释机器代码，再回答提问。
- 每个提问用单独一行回答。
- 输入机器代码的第一行为程序的装载地址。
- 机器代码需要装入内存执行（即部分代码可能会修改其它代码）。
- 程序仅在用户模式下运行（即无需实现 `HALT` 以外的中断和权限管理）。
- 在遇到 `HALT` 后即可结束解释（不需要真正执行相应的 `TRAP`），PC 在 `HALT` 后仍要自增。
- 提问的内容可能是如下之一：
    - 寄存器：输入寄存器名，输出寄存器的值。被提问的寄存器可能是通用寄存器 `Rx` 或者程序计数器 `PC`。
    - 内存：输入内存地址，输出内存地址中的内容。
- 提问所用寄存器名为大写，十六进制数为小写。
- 提问部分的输入输出均为十六进制，数值包含 4 个数位，不足的部分在左侧补 0。
- 可以使用任何支持标准输入和输出的语言（也包括 LC-3！）来编写程序。

## 输入输出样例

输入：

```
0011000000000000
0101000000100000
1111000000100101

R0
PC
x3000
```

输出：

```
x0000
x3002
x5020
```
